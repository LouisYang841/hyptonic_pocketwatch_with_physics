# Hyptonic Pocket Watch with Physics

一个基于原生 HTML、CSS 和 JavaScript 的交互式物理模拟：用独立的小刚体链节和转轴铰链构建一条可摆动、可拖拽、可抛甩的怀表链，并实时渲染复古风格的机械怀表。

## 功能特性

- **刚体链条模拟**：由 28 个独立小刚体链节组成，链节之间通过转轴铰链连接。
- **直接约束求解**：使用块三对角矩阵与块 Thomas 算法求解铰链约束，减少链条拉伸和质量差异带来的误差。
- **牛顿迭代校正**：对非线性旋转约束进行迭代修正，保持链节间距稳定。
- **真实交互**：支持鼠标和触摸操作，可抓取怀表进行拖拽或抛甩。
- **拖拽弹簧模型**：怀表不会被直接“钉”在指针位置，而是通过临界阻尼弹簧跟随目标，交互更自然。
- **设备运动感应**：在支持的移动设备上，可使用陀螺仪/加速度传感器改变重力方向并产生惯性效果。
- **固定时间步长模拟**：采用子步进、固定 60Hz 物理时间步和渲染插值，提升动画稳定性。
- **复古怀表渲染**：包含金属外壳、象牙色表盘、罗马数字、指针、表镜反光和金属链环高光效果。
- **实时误差显示**：页面底部显示当前最大铰链节距误差，便于观察约束稳定性。

## 在线体验

如果仓库已配置 GitHub Pages，可通过仓库的 Pages 地址访问。也可以直接在本地运行 `index.html`。

## 本地运行

项目是一个无需构建工具的单文件网页应用。

### 方式一：直接打开

在浏览器中打开 `index.html` 即可体验基本功能。

### 方式二：启动本地 HTTP 服务器（推荐）

使用 Python：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

使用本地服务器运行时，浏览器通常可以正常处理运动感应相关的安全上下文要求。移动设备访问时，建议使用 HTTPS；部分 iOS 浏览器还需要点击“启用运动感应”并授予权限。

## 操作说明

- **鼠标/触摸拖拽**：按住怀表并移动，可拖动怀表。
- **抛甩**：快速拖动后释放，怀表会保留惯性继续运动。
- **移动设备倾斜**：点击“启用运动感应”后倾斜设备，可改变模拟中的重力方向。
- **重置模拟**：刷新页面即可重新初始化链条和怀表。

## 技术概览

核心模拟流程位于 `index.html` 中：

1. 创建链节和怀表对应的刚体状态，包括位置、速度、角度、角速度、质量和转动惯量。
2. 使用半隐式欧拉方法预测刚体运动。
3. 通过铰链约束建立块三对角系统。
4. 使用块 Thomas 算法直接求解约束修正量。
5. 通过牛顿迭代降低铰链位置误差。
6. 根据位置差分回写速度，并施加空气阻尼和铰链摩擦。
7. 使用 Canvas 绘制链条、怀表和实时状态信息。

主要参数包括：

- `LINK_COUNT`：链节数量，默认值为 `28`
- `LINK_LEN`：链节间距，默认值为 `16`
- `WATCH_RADIUS`：怀表半径，默认值为 `65`
- `SUBSTEPS`：每帧物理子步数，默认值为 `8`
- `NEWTON_MAX`：每个子步的最大牛顿迭代次数，默认值为 `8`
- `BASE_GRAVITY`：模拟重力加速度，默认值为 `980 px/s²`

## 兼容性说明

- 需要支持 Canvas、Pointer Events 和现代 JavaScript 的浏览器。
- 鼠标和触摸拖拽功能适用于桌面和移动端浏览器。
- 运动感应需要 HTTPS 或 `localhost` 等安全上下文。
- 如果浏览器或设备不支持运动感应，页面会自动降级为固定方向重力模拟。
